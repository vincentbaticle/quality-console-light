Recorded examples

What the captures recorded from real calls and real events, and the tests that replay it.

A hand-written example is a guess about what a neighbour says. A recording asks the real one, keeps the transcript in a journal (capture/, never committed), then a merge writes the examples the tests read (contracts/, committed, reviewed in a diff). The tests then run against testcontainers neighbours fed with those examples: Microcks replays the partner's answers, and the events of the code are compared with the recorded ones.

Prism or Microcks? Not rivals, two jobs. The contract mocks (Prism, the 🎭 links of API docs) answer any contract with the same example, for anyone trying an API by hand. Microcks serves the recorded examples of this page to the tests, the answer picked by request (ada gets ada's balance, an unknown account its 404).

This page only reads. To record again, run the commands of each card in a terminal, then reload.
