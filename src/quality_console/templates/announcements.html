Release announcements static

The release announcements of each system, as /announce-release drafts them for Slack: one short message for a whole system, from the changelogs of all its components.

Nothing to click here: the drafts are read from announcements/. In Claude Code, /announce-release quality #platform-releases resolves the components of the system in the catalog, reads their changelogs since the last announcement, drops the noise (bots, CI, chores), adds the ticket and merge request context, and drafts 10 to 15 lines: a title with the version, one context sentence, 1 to 3 headline features, the fixes, the actions users must take, then Tickets: and Versions:. It saves a Slack draft and never posts: the developer reads it and sends it.

Where the next run starts comes from the Versions: line of the newest announcement of each system: the skill reads it back in the channel, so a second run only covers what changed since.
